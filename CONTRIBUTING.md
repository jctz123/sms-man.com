# Contributing

Thanks for helping improve this independent SMS-Man information guide.

## What we welcome

- Corrections to factual statements, with links to official sources.
- Improvements to the English, Simplified Chinese, and Vietnamese documentation.
- Clarifications about documented API behavior.
- Better explanations of privacy, security, and responsible-use considerations.
- Fixes for broken links or formatting.

## Contribution guidelines

1. Keep the project independent and clearly unofficial.
2. Prefer official SMS-Man documentation for product behavior, API details, prices, availability, and policies.
3. Do not add unverified prices, country inventories, success-rate claims, or guarantees.
4. Do not publish API keys, account credentials, personal data, SMS contents, or private screenshots.
5. Do not add instructions intended to bypass platform safeguards, impersonate others, commit fraud, or facilitate spam.
6. When changing one language, check whether the corresponding information needs updating in the other language files.
7. Keep links descriptive and verify them before submitting.

## Pull requests

Please explain:
- What changed.
- Why the change is needed.
- Which language files are affected.
- Which official source supports any factual change.

For security-sensitive issues, do not publish credentials or exploit details in a public issue. Contact the relevant service provider through its official support channel.
