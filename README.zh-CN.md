## SMS-Man 是什么？

SMS-Man 是一个在线虚拟号码和短信接收平台。用户可以根据平台当前提供的国家、地区和应用选项，购买用于短信激活的号码，并在 SMS-Man 账户中查看收到的短信。对于需要在一定时间内多次接收短信的场景，平台还提供号码租用服务。

需要注意，虚拟号码并不等同于个人长期使用的手机号码。号码可能具有临时性、共享性或回收再分配等特点，也可能受到目标网站、应用或运营商的限制。SMS-Man 页面显示有库存，并不代表目标平台一定会接受该号码。

## SMS-Man 的基本工作方式

一般使用流程如下：

1. 在 SMS-Man 官方网站注册或登录。
2. 查看当前可选国家、应用、号码类型和价格。
3. 根据实际且合规的用途选择号码产品。
4. 按照 SMS-Man 账户页面的提示操作。
5. 如果短信成功送达，在账户后台查看收到的消息。
6. 根据官方规则取消、管理激活订单或结束号码租用。

具体界面和操作规则请参考 [SMS-Man 官方帮助中心](https://sms-man.com/cn/help?ref=ceLde1noXEm-)。

## SMS-Man 主要功能

根据官方页面和帮助文档，SMS-Man 提供的功能主要包括：

- **在线接收短信：** 通过在线账户查看发送到所购号码的短信。
- **国家和地区选择：** 根据当前库存选择可用国家或地区。
- **应用选择：** 从平台当前列出的应用或服务中选择目标项目。
- **一次性短信激活：** 在支持的场景下购买用于单次短信验证的号码。
- **号码租用：** 对于需要在租用期间接收多条短信的场景，可以查看号码租用选项。
- **开发者 API：** 支持查询余额、号码库存或价格、申请号码、获取短信以及更改激活状态等自动化操作。
- **兼容 API：** 提供另一套兼容格式的 API 接口，方便开发者进行集成。

以上为功能概述，不代表所有国家、应用和号码类型都始终开放。

## 一次性接码与号码租用有什么区别？

| 对比项目 | 一次性短信激活 | 号码租用 |
|---|---|---|
| 主要用途 | 接收一次短信验证码 | 在租用期内接收多条短信 |
| 使用时间 | 按激活订单计算 | 按选定租期计算 |
| 多条短信 | 不应默认支持 | 具体取决于租用产品规则 |
| 可用情况 | 取决于国家、应用和库存 | 取决于国家、租期和库存 |
| 适合场景 | 合规的一次性、低风险验证 | 确实需要持续接收短信的合规场景 |

SMS-Man 官方帮助中心说明，**Receive SMS** 页面中的号码通常只能接收一条短信；如需接收多条短信，应查看号码租用服务。购买前仍应以当前产品说明为准：[官方帮助中心](https://sms-man.com/help?ref=ceLde1noXEm-)。

## SMS-Man 接码使用步骤

官网界面可能调整，以下是根据官方帮助文档整理的一般流程：

1. **注册或登录：** 打开 [sms-man.com](https://go2lk.pages.dev/ea9735) 并登录账户。
2. **确认产品信息：** 检查国家、应用、号码类型、价格及相关限制。
3. **选择可用号码：** 通过官网当前提供的购买入口选择号码。
4. **合规使用号码：** 仅在目标服务允许使用虚拟号码，且符合其服务条款的情况下填写号码。
5. **查看短信：** 返回 SMS-Man 账户，查看是否收到短信。
6. **完成验证：** 只有在目标服务接受该号码且短信成功送达时，才能完成验证。
7. **管理订单：** 根据官方说明取消激活或管理租用号码。

如果没有收到短信，请按照官方帮助中心的等待、取消、重试或联系客服流程处理。退款资格以服务商当前政策为准，不应默认所有失败订单都可以退款。

## SMS-Man API 开发接入

SMS-Man 为开发者提供 API 文档。官方目前公开了 API v2.0 和兼容 API 两类文档。正式开发前，请先阅读对应版本的官方说明：

- [SMS-Man API v2.0](https://sms-man.com/cn/api)
- [SMS-Man 兼容 API](https://sms-man.com/cn/api/compatible)

### API v2.0

官方 API v2.0 文档给出的请求入口为：

`https://api.sms-man.com/control/`

文档列出的主要操作包括：

| 操作 | 用途 |
|---|---|
| 查询余额 | 获取账户余额 |
| 获取限制 | 查询国家和应用组合的号码可用情况 |
| 请求号码 | 为指定应用申请号码 |
| 获取 SMS | 获取订单对应的短信 |
| 更改请求状态 | 更新激活订单状态 |
| 获取当前价格 | 查询价格和库存数据 |
| 获取国家列表 | 获取平台支持的国家列表 |
| 获取服务列表 | 获取平台支持的应用或服务列表 |

API 请求需要使用账户 API Token。具体参数、请求方法、响应结构和状态值请以[官方 API 文档](https://sms-man.com/cn/api)为准。

### 兼容 API

兼容 API 文档提供的接口地址为：

`https://api.sms-man.com/stubs/handler_api.php`

该接口使用 `api_key` 参数，并提供余额查询、价格查询、申请号码、获取国家和服务列表、更新激活状态等操作。具体请求参数和响应格式请参考[官方兼容 API 文档](https://sms-man.com/cn/api/compatible)。

### API 安全建议

- 将 API Token 保存在环境变量或密钥管理服务中。
- 不要将 API Key、Cookie、密码或个人数据提交到公开 Git 仓库。
- 不要在浏览器端 JavaScript 中暴露 API 凭据。
- 如果密钥意外公开，应立即更换。
- 为请求设置超时、错误处理，并关注接口调用限制。
- 日志中尽量只保留请求 ID 和非敏感诊断信息，不要记录短信正文或密钥。
- 仅在合法、获得授权且符合 SMS-Man 和目标平台条款的场景中使用 API。

本仓库不包含 API 客户端，不代理短信，也不会收集用户凭据。

## 隐私与安全注意事项

虚拟号码可以用于测试等合规场景，但也存在一些风险：

- **账户找回：** 后续可能无法继续控制该号码，因此不适合依赖短信找回的重要账户。
- **号码再次分配：** 临时号码或回收号码未来可能被分配给其他用户。
- **共享访问风险：** 不应将虚拟号码视为私人、永久的手机线路。
- **第三方平台限制：** 部分网站可能屏蔽虚拟号码，或在条款中禁止相关使用方式。
- **敏感账户风险：** 不建议将临时号码用于银行、金融、医疗、政府服务或包含敏感个人信息的账户。
- **合规要求：** 使用时应遵守当地法律、SMS-Man 条款及目标服务的规则。

不要使用虚拟号码冒充他人、规避平台安全措施、批量创建欺诈账户、绕过访问控制，或从事垃圾信息、诈骗、骚扰等滥用行为。

## 常见问题 FAQ

### SMS-Man 是免费的吗？

SMS-Man 属于商业服务。具体价格、支付方式和促销活动请以官网当前页面为准。

### SMS-Man 可以在线接收短信吗？

SMS-Man 的主要用途之一就是通过在线账户查看发送到平台所提供号码的短信。能否成功接收取决于号码库存和目标服务的验证规则。

### 一个 SMS-Man 号码可以接收多条短信吗？

### SMS-Man 提供 API 吗？

### SMS-Man API Key 在哪里查看？
